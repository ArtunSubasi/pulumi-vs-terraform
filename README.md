# Terraform vs. Pulumi: 100% Code, 0% Slides

Demo repository for a 45-minute talk. Every showcase is a self-contained project, once in
Terraform (HCL) and once in Pulumi (TypeScript), so a failure can't cascade and you can
jump to any of them. Everything runs offline with local state. No cloud account needed
(yet: AWS comes in Phase 2, see [`PLAN.md`](PLAN.md)).

- **Talk on one page:** [`CHEATSHEET.md`](CHEATSHEET.md)
- **Plan, decisions, status:** [`PLAN.md`](PLAN.md)
- **Verified OpenTofu/Terraform feature claims:** [`docs/feature-claims.md`](docs/feature-claims.md)

## Usage

```bash
make prep          # once, with network: provider mirror, npm deps, Pulumi plugins + template
source scripts/env.sh   # in every demo terminal: offline provider mirror, quiet Pulumi
make check         # rehearse: apply + test + destroy every final/ (needs a clean state)
make reset         # wipe all state, .terraform/, workspaces, stacks, generated files
make reset-live    # reset + restore every live/ dir (throws away what was typed)
make check ONLY="02 05"   # any target can be limited to some showcases
```

**Before going on stage:** `make reset-live && make prep && make check && make reset`, then
`source scripts/env.sh` in each terminal. After that, nothing needs the network.

### Pulumi passphrase

Pulumi encrypts secrets with a per-stack key, and with the local file backend that key
comes from a passphrase. It is **never committed**. Enter it when prompted, or set it in your
own shell:

```bash
export PULUMI_CONFIG_PASSPHRASE='...'   # your own value, not stored anywhere in this repo
```

`make check` generates a random one for its own run if none is set. Every stack it creates
is removed again.

As a consequence, no stack file containing an `encryptionsalt` or `secure:` value is
committed. Plain stack config (05) is committed. Stacks and secrets are created with the
commands in each README, and `make reset` puts committed stack files back to their
salt-free version.

### Where state lives

- **Terraform:** `terraform.tfstate` next to the code (`terraform.tfstate.d/` for workspaces).
- **Pulumi:** `.pulumi-state/` next to the code. Every `Pulumi.yaml` sets
  `backend: url: file://./.pulumi-state`, so no `pulumi login` is needed.

All of it is git-ignored, as are `.terraform/`, `node_modules/`, `sdks/` (generated by
`pulumi install` from `packages:` in `Pulumi.yaml`), `out/` (files the demos write) and
`.cache/` (the provider mirror).

## Repository conventions

- `.terraform.lock.hcl` (hashes for linux/darwin/windows × amd64/arm64) and
  `package-lock.json` are committed.
- Terraform code is plain Terraform. OpenTofu-only features live in `*.tofu` files in a
  separate `opentofu/` dir (Terraform ignores `*.tofu`).
- Neutral tone: the code shows the trade-offs. Verdicts are given verbally, not in the code.
